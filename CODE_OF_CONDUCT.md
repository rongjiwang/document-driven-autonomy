# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

## Our Pledge

We pledge to make participation in this project a respectful experience for everyone.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect differing viewpoints and experiences.
- Give and receive constructive feedback professionally.
- Focus criticism on ideas and contributions, not people.

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks.
- Trolling, insulting comments, or sustained disruption.
- Publishing private information without permission.
- Other conduct that would reasonably be considered inappropriate in a professional setting.

## Enforcement

Maintainers may remove comments, close issues, or restrict participation when behavior does not meet this standard.

Instances can be reported through the repository's maintainer contact path or GitHub reporting tools.
